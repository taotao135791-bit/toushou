# FB 读数：多账户上手指南

适用于任何同事，无需开发背景。中文和英文 Facebook 界面都支持。

## 三步上手

1. **登录 Facebook**：打开应用右侧的浏览器面板，登录你的 Facebook 个人号。登录态会保留，下次不用重复登录。
2. **添加广告账户**：在浏览器面板里点进你想看的广告账户（页面打开后即可），回到看板任意「FB 读数」模块 → 配置模块 → 管理账户 → 点「从当前页面获取账户」，账户 ID 会自动填入，起一个好认的别名（如 三国-AND），点添加账户。
3. **建模块读数**：看板页 → 添加模块 → FB 读数 → 勾选账户 → 创建。点模块上的「刷新」或工具栏的「刷新全部 FB 读数」即可出数。数据带时间戳，CTR/CPM 等指标以页面实际渲染的列为准，没有的列如实显示「—」。

## 常见提示速查

| 提示 | 原因与处理 |
| --- | --- |
| Facebook 未登录 | 先在右侧浏览器面板登录，再回来点刷新 |
| 页面加载中断或超时 | 网络波动，直接重试一次即可 |
| 另一个读数正在进行 | 等当前刷新完成再点 |
| 读数未通过验证 | 页面数据未通过行数/合计校验，重试；持续出现时把错误码（括号内）发给维护者 |
| 返回的账户或日期与模块不一致 | 页面口径与模块设置不符，检查模块的账户和日期口径 |

## 边界（重要）

- Facebook 全程只读，任何刷新都不会改预算、出价或广告设置。
- 数字仅来自已验证的页面读数；没读到就是「—」，不会估算。
- 一个浏览器面板对应一个 Facebook 个人号；换个人号需先退出再登录。
- 每个账户的列视图各不相同，解析按页面表头自动识别；遇到极少数未收录的列会安全失败并显示错误码，由维护者补充字典后即可。
