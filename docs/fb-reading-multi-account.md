# FB 读数：多账户上手指南

适用于任何同事，无需开发背景。中文和英文 Facebook 界面都支持。

## 三步上手

1. **登录 Facebook**：打开应用右侧的浏览器面板，登录你的 Facebook 个人号。登录态会保留，下次不用重复登录。
2. **添加广告账户**：在浏览器面板里点进你想看的广告账户（页面打开后即可），回到看板任意「FB 读数」模块 → 配置模块 → 管理账户 → 点「从当前页面获取账户」，账户 ID 会自动填入，起一个好认的别名（如 三国-AND），点添加账户。
3. **建模块读数**：看板页 → 添加模块 → FB 读数 → 勾选账户 → 创建。点模块上的「刷新」或工具栏的「刷新全部 FB 读数」即可出数。数据带时间戳；CPM/CTR 从已验证的展示、点击、消耗重算，缺分母时如实显示「—」。
4. **账户可用额度**：在模块配置中勾选「可用额度」后，模块会显示最近一次额度。它与消耗/CPI 读取分离：点「刷新」只更新广告读数；点「刷新额度」才会按账户打开只读的 Meta「账户概览」，并从页面明确标注的「账户花费限额」和「已花费」计算剩余可花额度。产品汇总只在币种和口径一致时相加。此口径不等同于 Billing 页的当前欠款余额。

## 产品级汇总

同一个产品想看总消耗时，使用同一个「FB 读数」入口：

1. 勾选多个账户（例如 三国IOS、三国AND）。
2. 点「创建一个产品汇总模块」。
3. 在汇总模块点「刷新」，系统会按同一日期口径串行刷新所有账户。

汇总规则：消耗、展示、点击、安装先相加；CPI = 总消耗 ÷ 总安装，CPM = 总消耗 ÷ 总展示 × 1000，CTR = 总点击 ÷ 总展示，CPA = 总消耗 ÷ 同一种成效数。任何一个账户或缺分母列未验证时，顶部总汇总显示「—」并提示覆盖状态，不会用平均值或估算补数。每个账户的明细行仍会显示已验证数据。

## 常见提示速查

| 提示 | 原因与处理 |
| --- | --- |
| Facebook 未登录 | 先在右侧浏览器面板登录，再回来点刷新 |
| 页面加载中断或超时 | 网络波动，直接重试一次即可 |
| 另一个读数正在进行 | 等当前刷新完成再点 |
| 可用额度未更新 | 额度不会跟随「刷新」自动读取；需要单独点「刷新额度」 |
| 读数未通过验证 | 页面数据未通过行数/合计校验，重试；持续出现时把错误码（括号内）发给维护者 |
| 返回的账户或日期与模块不一致 | 页面口径与模块设置不符，检查模块的账户和日期口径 |

## 边界（重要）

- Facebook 全程只读，任何刷新都不会改预算、出价或广告设置。
- 数字仅来自已验证的页面读数；没读到就是「—」，不会估算。
- 一个浏览器面板对应一个 Facebook 个人号；换个人号需先退出再登录。
- 每个账户的列视图各不相同，解析按页面表头自动识别；遇到极少数未收录的列会安全失败并显示错误码，由维护者补充字典后即可。
