# 界面精修待办

记录日期：2026-11-04。观察版本：macOS 正式版 2.2.0。

本文件记录审查建议及测试分支进展，不代表已经发布。保持现有功能、权限、数据口径和工作流；保留黑白灰风格、原生窗口外形及红绿灯大小。只记录概括性界面现象，不保存真实账户、指标、对话原文、凭据或私人路径。

## 对照范围

- 实际操作投手：首页、长对话、今日读数、模块化看板、连接页。
- 实际操作豆包工作：首页、工作环境菜单、项目选择入口。
- ChatGPT 本体被电脑控制工具禁止访问，仅参考用户此前提供的界面截图；不声明实际操作验证。

## 建议顺序

1. **对话过程与结果层级**：工具调用默认显示易懂的动作、来源及状态，保留可展开的原始参数和结果。评估合并连续过程记录、过滤无实质内容的中间片段，以及避免为这些片段显示「加入看板」。错误和需要用户处理的审批仍须清楚显示。让最终结论、图表与看板重点画面更突出。
2. **输入框比例与状态**：降低空输入框的默认高度，随内容增长；统一权限、模型、思考和发送控件的基线、间距及高度。明确聚焦、可操作和禁用状态，保留现有输入与发送行为。
3. **今日读数布局**：将账户、日期和读取操作组织成紧凑的一组，保留快捷日期及日历；完整口径可按需展开，当前范围和结果状态持续可见。区分读取、保存和 AI 分析的主次。
4. **连接页卡片规范**：统一官方 Logo 占位、标题、状态、描述及操作区的布局。默认突出连接状态与常用操作，权限清单、到期时间和技术细节按需展开，保留现有授权与断开流程。
5. **看板阅读与编辑层级**：减弱点阵背景和非必要边框；统一指标字号、数字字体、单位及小数格式。改善长标题显示，减少静态标题与当前日期范围的歧义。保留模块调整、配置和展开能力，提升阅读时的内容占比。
6. **全局一致性**：统一圆角、边框、图标粗细、按钮尺寸、菜单间距、键盘焦点和轻量反馈；对主题及不同窗口尺寸分别核验。优先保持导航、滚动和当前上下文稳定。

## 进一步检查：对话流

继续使用正式版进行只读界面检查，关注：

- 用户消息、思考、工具调用、中间回复、最终结果的分组与阅读顺序。
- 过程记录的默认展开程度，动作名和参数是否易懂。
- 复制、编辑、加入看板等操作与实际消息内容是否匹配。
- 看板重点预览、打开看板及返回对话是否衔接清楚。
- 长对话滚动、回到最新消息、页面切换后的阅读位置和输入区占比。

本轮不发送新提示、不修改广告账户、不创建或删除用户看板，也不将私人界面内容写入仓库。代码推断与实际复现分别记录。

### 第二轮细节修正

- 本地内置六个官方品牌标识，来源与图像摘要记录在 `src/renderer/assets/brands/SOURCES.md`。连接卡、工具步骤和已知读数模块显示对应标识，未知工具保持通用图标。
- 明确网页 URL 只保留来源主机名，不从搜索词或任意工具输出猜测网站；已知服务复用本地标识。其它网站由 Main 匿名获取固定 `/favicon.ico`，不跟随重定向，不携带 Cookie、Authorization 或 Referer；DNS 和连接地址校验阻止内网请求，原 renderer CSP 不变。GitHub 在代理假 IP 环境从其官网声明的官方 PNG 常量地址补取，不将客户域名或子域交给第三方图标服务。仅接受有尺寸上限的 PNG/ICO，检查 PNG 分块并拒绝动画，将固定 MIME 的 data URL 交给隔离的 Chromium 图片解码；不依赖 macOS 无法读取部分 ICO 的原生图像接口。
- 图标可见后才请求，采用有界队列、并发和缓存，超时回退。当前系统代理 DNS 会把公网域名解析到特殊地址，首次源站直连测试触发安全回退，因此增加受控 GitHub 补取；不放宽任意源站私网过滤。系统 DNS 未完成的任务继续占用底层并发槽，避免不可取消的解析无限累积，极端情况下图标持续回退，业务查询不依赖图标。
- 发送气泡改用独立主题底色；回复操作均常驻，语言移到设置。修复中性主按钮在深色主题下的前景色，危险确认按钮加深红底；任务保存和 Figma 连接补同步连点防护及迟到结果保护。
- 看板默认纯色更柔和，今日读数不继承看板自定义网格；保留显式自定义外观。缩放手柄保留 28px 命中区域，去除圆框，只显示轻量角标。工具展示按不可变记录及语言使用弱引用缓存，不持久保存工具数据。

- 成品实际发现聊天保存弹窗被消息行的 `content-visibility` 裁切，改为 body Portal，修复保存、关闭、焦点和嵌入浏览器遮挡；同类任务及回滚弹窗同步修正。今日页移除居中窄容器的内层滚动，统一由右侧内容区滚动，顶部标签与左侧栏保持独立。
