# V2.0.0：HTML 看板与对话高光

> V2.0.0 已于 2026-11-01 [公开发行](https://github.com/taotao135791-bit/toushou/releases/tag/v2.0.0)。下文分别记录产品功能、实际验证范围与限制。

## 使用流程

在「今日」页选择一个 TikTok 账户或所选账户范围，选用今天、近 7 天、近 28 天，或最多 366 天的自选起止日期。账户名与 ID 一起显示；逐账户读数、失败、取消和未尝试状态分别展示。Facebook 使用报表链接并校验账户及日期；Google 读数按其独立报表范围展示。TT 今天的数据截至读取时，对比昨天全天，两者不是相同经过时间；近 7 / 28 天按各 TT 账户时区截至昨天。平台是否保留所选历史数据以实际返回为准。

读取完成后可「保存为新看板」，在弹窗中选择新建或追加到已有看板；也可选择「用 AI 生成看板」。追加时校验目标版本，保存后打开目标看板；默认选择模块化布局，也可选择整页报告。模块化布局保留完整来源快照，分别创建覆盖、说明和所选图表；单账户还会生成独立指标卡，多账户不强行合计不同口径。图表默认勾选，可取消。选择 AI 生成时编辑本次新增的模块。快照固定保存当时选定范围、账户状态、日期、来源时间、币种和读数；后续刷新不会改写它。读取广告报表本身不调用模型。多账户读取上限为 500 个；主动发起 AI 分析或布局生成时最多向模型提供当前范围的 50 个账户，超过部分会标明省略。单账户分析可减少上下文和 token 用量。

在看板中可分别拖动、调整大小、展开或编辑各模块。选择「编辑模块」或整页报告的「修改看板」，用自然语言描述希望修改的标题、布局或风格，生成后先预览，再选择「采用并保存」。高级 HTML/CSS 默认折叠，仍可按需打开。指标卡及柱状图、饼图、环形图可绑定保存的读数，不需要重新请求广告平台；可选 CSS 入场动画，并可展开查看数据说明。图表按平台、币种、日期和时区分别展示，失败或缺失数据不按零处理。快照不是实时数据；没有日粒度时序时，不能生成每日趋势图。保存失败时保留建议供重试；未保存修改在关闭前有提示。AI 生成不保证结论正确，文字和展示仍需用户审核。

对话创建组件后可直接看到已保存组件的预览，并可打开看板定位；普通 HTML 文件使用静态预览，内容未经快照验证。HTML 代码默认折叠在高级详情中。未恢复的历史会话可能暂不能预览，可恢复会话或打开看板查看。

用户也可主动从读数或看板发起对话分析。对话高光引用具体账户和指标，应用前检查快照版本、数值及来源，过期或不匹配的证据不能应用；用户可查看证据并确认加入看板。校验数字不等于证明自然语言结论，仍应人工判断。对话里的证据可跳回快照；确认后写入看板的便签保存审核文字，便签本身没有证据跳转。广告平台读数使用只读请求，不修改广告、预算或状态。

## 数据、导出与模型

用户主动发起分析或编辑时，所选账户的名称、ID、指标、日期和结果类型，以及当前布局和用户输入，可能发送给所选模型。应用不会主动将存储的广告凭据、Cookie 或模型密钥作为提示内容；请勿在描述或自定义布局中填写密钥。模型调用使用量由服务商计费；首次建议格式不符合要求时，系统可能自动修复一次，产生额外模型用量。单次读取数据本身不消耗模型 token。

自定义看板可导出自包含的本地离线 HTML。默认匿名选项隐藏内置读数及绑定中的账户标识，但指标数字仍可能敏感，用户输入的标题、文字和属性不会自动脱敏；分享前应检查完整文件。用户可主动选择实名导出。本次不提供托管分享链接，也不会自动刷新导出的文件；文件交付后由用户自行管理。

AI 编辑使用隔离运行环境，支持 `models.yml` 中的 API key 和受支持的环境变量密钥；仅有运行时密钥库或 OAuth 登录的模型暂不支持该功能。这不改变普通对话或广告平台 MCP 连接。使用合成账户数据，DeepSeek V4 Flash 已通过服务级验证及候选正式包中的模块生成、预览、采用保存、关闭和重新打开验证；该结果不能代替其他模型或真实账户验收。

HTML 模板和 CSS 使用受限的标签、属性、选择器及样式；预览采用沙箱，默认不允许脚本或外部资源。用户输入仍应在导出前检查，不能把默认匿名选项当成对整份自定义文件的自动脱敏。测试源码和公开产物只能使用合成或脱敏数据，不包含真实账户、私人来源链接或凭据。

## 升级与降级

V2 使用独立的 `kanban-boards-v2.json`。首次读取时，应用严格校验可识别的旧版数据，将原文件复制到新版路径，并保留旧版 `kanban-boards.json` 及独立备份 `kanban-boards-pre-v2-backup.json`；后续新版保存不写回旧版路径。旧版 columns/cards 的非空备注迁为单独便签，原始模板和时间信息仍在备份。未知格式、损坏数据或无法安全备份时会停止，而不是静默覆盖。细节见[看板升级和降级](multi-platform-readings.md#看板升级和降级)。

降级后旧版看到升级前的数据，两版后续编辑不会自动合并；旧版再次运行仍可修改旧文件。升级、降级或手动恢复前应退出应用并备份全部看板文件，不要把新版文件覆盖到旧版路径。独立导出的 HTML 不会反向更新看板。
