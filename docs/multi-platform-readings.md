# 多平台读数

v1.4.6 实现了 TT 和 Google 读数扩展。FB 继续使用现有报表链接和导出校验流程。

## 使用

- TT：在「连接」完成 TikTok 官方授权，打开「今日」或在具体看板中添加「TT 读数」。账户发现、信息和报表均使用应用自身的 MCP 连接，仅调用三个只读工具；看板读数不使用粘贴的 Open API token 兜底。
- Google：在具体看板的「添加模块」选择「Google 读数」，配置完整 Google Ads 链接，使用「打开来源 / 登录」在内置浏览器登录，再点「读取链接」。也可通过原生文件选择器「导入 CSV」。
- Google 目前自动识别广告系列表格的下载入口。页面必须明确显示单一账户、日期、费用列中的 USD 和 GMT 时区；不能核实就拒绝读取。其他页面布局、币种及报表编辑器的自动导出仍需扩展和实测。
- 手动 CSV 导入不借用当前浏览器的账户身份；文件本身须包含账户 ID、币种、日期范围、广告系列和费用。支持 UTF-8 与带 BOM 的 UTF-16LE。

Google 显示导出本身的日期与筛选范围，不跟随看板总控日期改写。TT 近 7 / 28 天截至昨天，使用明确标注的本机日期窗口；与广告账户时区不同的情况需由使用者核对。看板近 30 天不会再被静默映射为 TT 近 28 天，不等窗口会保持独立。

TT 未知或混合币种时不显示金额合计。不同账户或不同 ID 的同名广告系列分别统计。Google 各账户保留自己的币种，平台转化定义保持独立，缺失列显示「—」。

旧的「TikTok 报表」数据集和定时同步服务沿用原有 Open API 路径；本次 MCP 切换范围是账户读数、TT 看板模块和今日页。

## 数据与安全边界

Renderer 只提交有界链接和已保存模块 ID，Main 校验、采集、解析并持久化，通过 typed preload 返回。Google 下载只点击明确的表格下载和 CSV 控件，不保存远端报表，不修改广告、预算、状态、账户或列配置。

Google 拒绝非 HTTPS、非 ads.google.com、含 URL 凭据或常见密钥参数的链接。导出前后账户、日期和来源必须一致；CSV 自有字段与页面证据冲突时拒绝。明确的当前视图总计会与可加明细核对，其他总计不混加。导入失败保留旧的有效读数。更换链接后会明确标注旧读数来自之前的链接；手动导入单独标明 CSV 来源。Google 模块始终按独立报表范围显示，整板刷新也包含它。

原始自动下载 CSV 仅供当次解析，导入完成后删除；下载失败、取消或上下文改变也清理临时文件。目录 0700、CSV 和汇总存储 0600。用户手动选择的原文件不删除。

真实账户仅用于只读验证。测试源码和报告使用虚构数据或汇总结论，不包含真实账户名称、ID、私有来源 URL、原始报表或令牌。没有向外部发送报告或修改广告账户。业务读数在用户本机保留实际身份以支持账户选择，不能将它直接当成可公开的脱敏材料。

## 验证记录（2026-10-29）

TT 已通过真实 Electron 和应用自身 OAuth 凭据完成只读验收：最新版 MCP 发现 6 个授权账户，近 7 天读数 6 成功、0 失败，汇总与逐账户结果一致。另以 30 天报表对比正常与小分页请求，最多 10 页，行数及消耗汇总一致。登录恢复由用户自行完成；最终复测没有续期或写入凭据。

用户选择暂不进行 Google 真实账户验收。因此 Google 的结果只证明本地流程，不能视为真实 Google Ads 页面可用性已经通过：

- 本地真实 Electron 虚构页面：两个下载入口只命中表格；可信页面范围、实际 CSV 下载及解析通过；其他列出现 USD 不会被当成费用币种。
- 隔离配置的真实桌面界面：非 Google 链接无法保存；原生 CSV 选择器导入后数值正确更新；缺少范围的 CSV 被拒绝并保留旧值。没有使用真实 Google 账户。
- 全量 151 个测试文件、1,578 项测试通过（启用必须执行的 Electron E2E）；类型检查和生产构建通过。OMP 当前配置的 21 项兼容测试通过，旧版 pi 因未安装而跳过。Google 解析和存储另覆盖日期后缀、总计不一致、UTF-16LE、上下文冲突、损坏存储和权限。
