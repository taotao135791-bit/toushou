# 多平台读数

v2.0.1 支持 Facebook、TikTok 与 Google 多平台看板读数。FB 使用报表链接和导出校验流程；Google 的支持范围与真实账户验收限制见下文。

## V2.0.0：读数与看板

- 今日页可用日历选择单日或起止日期，最多 366 天，今天/近 7 天/近 28 天保留为快捷按钮。TT 按每个账户的时区核对所选日期；自选结束日期晚于该账户今天会明确失败，不会截断。FB 自选日期会构建精确的只读链接，仍须来源页账户和日期完全匹配才接受；尚未验证真实 FB 任意历史日页面。
- TT 快捷日期按各账户完整日计算；“今天”是读取时的数据，对比昨天全天，界面明确提示不是等时段。账户行保留各自报告窗口，跨时区不再套用本机昨天。
- TT 逐账户展示进度和已完成读数，取消保留已完成/失败项并标记未尝试项，取消任务不替换数据集；单行刷新保留其他账户结果。可在结果中搜索和筛选失败，排序在币种分组内进行。
- 用户可对单个 TT 账户或当前范围主动发起 AI 分析，也可将当前显示范围保存为看板；所选账户的名称、ID、读数和日期可作为模型上下文，不覆盖已有聊天草稿。Facebook 刷新失败或历史加载错误不作为正常读数进入分析；混合/未知结果类型和缺失结果不计算合并成本，未知币种明确展示。
- 点击“保存为新看板”后可选择新建或追加到已有看板，保存当前范围、各账户日期、来源时间和读取状态；追加前校验目标看板版本，保存后打开目标看板；默认模块化并勾选图表，也可选择整页报告或取消图表。模块可独立拖动、调整大小和编辑，来源快照单独保留；选择 AI 生成时编辑本次新增模块。后续刷新不会改写已存快照，保存失败保留当前读数。
- 已存快照可导出自包含 HTML 文件，默认匿名并去除账户标识和自由文本错误详情；可离线打开或分享文件。HTML 自定义与带证据的对话高光已通过候选正式包交互验收；本版不提供托管分享链接；详见 [HTML 看板说明](v2-html-board-evaluation.md)。
- 本地快照仍保留实际身份；HTML 默认匿名后指标数字仍可能敏感，用户自行编辑的 HTML 标题、文字和属性不会自动脱敏，分享前应自行检查。新版使用独立看板数据文件并保留原版文件，降级后仅看到旧版数据，两个版本的后续编辑不会自动合并。迁移无法安全完成时应保留原文件并提示，详见下方兼容说明。

自然语言看板编辑基于已保存的固定快照，不会为了修改布局重新请求 MCP 或刷新广告数据。用户主动生成时，所选账户名称、ID、指标和日期、已有布局及用户描述可发送给所选模型；应用不会主动收集广告凭据、Cookie 或模型密钥作为提示内容；用户自行输入的文字按其内容发送。建议先预览，明确选择“采用并保存”后才会落盘；保存失败保留建议供重试。受控数据绑定从固定快照填入指标和柱状图、饼图或环形图，不改写原始读数；可选入场动画及展开数据说明。快照不会实时刷新，也不包含每日时序，因此不应据此绘制每日趋势。首次建议格式不符合要求时可能自动修复一次，产生额外模型用量。未保存修改须先保存才能发起新的生成，失败或取消保留修改说明。

隔离的 AI 编辑仅支持 `models.yml` 里的 API key 配置及受支持的环境变量密钥。仅配置运行时密钥库或 OAuth 登录的模型暂不能用于此功能；不可用时会提示，不能据此推断普通对话或广告平台连接也不可用。DeepSeek V4 Flash 已使用合成数据通过服务级验证及候选正式包中的模块生成、预览、采用保存、关闭和重开验证；整页图表生成及导出也已验证。其他模型及凭据方式以实际配置和发行包验收为准。

## 自定义看板与对话高光

1. 在「今日」选日期和账户，读取后选择「保存为新看板」，在弹窗中选择新建或追加到已有看板；默认模块化，可改选整页报告，也可选择「用 AI 生成看板」保存快照并进入本次新增模块的编辑。追加时会校验目标看板版本，若已变化请刷新列表并重选。
2. 在看板中对单个模块选择「编辑模块」，或在整页报告中选择「修改看板」，填写希望调整的布局或标题，点击「生成修改建议」。AI 读取这份已保存快照，不会再次调用广告平台；可先预览，满意后点击「采用并保存」。保存失败时建议保留供重试；关闭时有未保存内容会提示。也可使用基础字段、布局模板和高级 HTML/CSS 编辑。
3. 从读数或已保存看板主动发起 AI 分析。对话高光可查看引用的账户和数据，并在人工确认后加入看板；引用的数字、数据版本及范围会校验，文字判断仍需人工审核。对话中的证据可跳回快照；保存到看板的便签保留审核文字，便签本身不提供证据跳转。
4. 对话里可预览已保存的看板组件并打开看板；普通 HTML 文件是静态预览，内容未经快照核验。源码默认折叠，历史会话恢复后若预览不可用，可恢复会话或打开看板查看。
5. 导出为本地离线 HTML。默认匿名只覆盖内置账户标识和受控数据绑定，用户输入的自定义标题、文字和属性不会自动脱敏；数值也可能敏感，请检查后再分享。此版本没有托管分享链接或自动更新链接。

主动发起分析或编辑会发送所选数据给模型，最多包含 50 个账户。读取报表不消耗模型 token；单账户分析可减少上下文和 token 用量。当天读数截至读取时，与昨天全天比较并非相同的经过时间；近 7 / 28 天按 TT 账户各自时区截至昨天。自选范围最多 366 天，历史数据是否可用以平台实际返回为准。

## 看板升级和降级

新版首次读取时会检查旧版 `kanban-boards.json`，将可安全识别的数据复制到独立的 `kanban-boards-v2.json`，并建立内容与原文件相同的独立备份 `kanban-boards-pre-v2-backup.json`；后续新版编辑只写新版文件。旧版 columns/cards 中的卡片标题迁为待办，非空备注迁为单独的便签；模板和卡片创建时间仍可在备份中恢复。未知字段、损坏数据、超出限制、已有备份内容冲突或未知新版格式会阻止迁移或保存，避免静默丢数据。迁移和异常提示已有合成测试覆盖。

降级后旧版读取原文件，看到的是升级前状态；旧版和新版之后各自的改动不会自动合并。旧版再次运行时仍可修改原文件；升级、降级或手动恢复前请退出应用并备份全部看板文件。若用户手动将新版数据复制到旧版路径，旧版保存任意看板时可能丢弃所有未知新版组件，不要这样做。独立导出 HTML 不会反向更新看板。

## 使用

- FB 今日页：先按名称或 ID 搜索已添加账户，选择单账户后点击「读取此账户」，或明确点击「巡检全部已添加账户」。初始仅展示选择器，账户名来自本机账户登记表；搜索筛选不改变全量巡检范围。通过「管理账户」发现、捕获、手动添加及移除本机账户；发现与读取仍依赖内置浏览器中的 FB 登录，不使用 TT 的授权接口。
- FB 巡检逐账户只读执行，显示已处理数；失败单独保留，登录或浏览器阻塞时停止后续账户。「停止后续读取」让当前账户完成后停止，不承诺中断已发出的浏览器请求。切换日期清除展示范围并使旧请求失效，需重新选择范围读取。保存与 AI 分析使用本次显示范围，未读取项标记为 unattempted，历史金额不作为本次成功结果。此轮验证使用虚构账户的 Electron 交互测试，未新增真实 FB 账户验收。

- TT：在「连接」完成 TikTok 官方授权，打开「今日」或在具体看板中添加「TT 读数」。账户发现、信息和报表均使用应用自身的 MCP 连接，仅调用三个只读工具；看板读数不使用粘贴的 Open API token 兜底。
- TT 多账户：未指定账户时读取连接页所选账户，未选择时发现全部授权账户；指定账户以数字 ID 确定范围。账户信息自动按每批最多 20 个获取，报表按账户读取，显示进度并支持取消。单次安全上限为 500 个账户；超过上限会提示缩小范围，不会静默遗漏。失败或未尝试的账户单独标记，不按零计算。
- TT 单账户：「今日」页根据账户名和 ID 选择一个账户读取，或主动巡检连接页所选范围；也可对已显示账户单独刷新，刷新不会改变连接页的全局选择或覆盖其他账户。可主动发起该账户的 AI 分析，所选账户名称、ID 与相关读数会发送给所选模型；不会自动修改广告。应用本身读取报表不调用大模型，提交分析对话才消耗模型 token。
- Google：在具体看板的「添加模块」选择「Google 读数」，配置完整 Google Ads 链接，使用「打开来源 / 登录」在内置浏览器登录，再点「读取链接」。也可通过原生文件选择器「导入 CSV」。
- Google 目前自动识别广告系列表格的下载入口。页面必须明确显示单一账户、日期、费用列中的 USD 和 GMT 时区；不能核实就拒绝读取。其他页面布局、币种及报表编辑器的自动导出仍需扩展和实测。
- 手动 CSV 导入不借用当前浏览器的账户身份；文件本身须包含账户 ID、币种、日期范围、广告系列和费用。支持 UTF-8 与带 BOM 的 UTF-16LE。

Google 显示导出本身的日期与筛选范围，不跟随看板总控日期改写。TT「今天」按每个广告账户的时区确定统计日期；账户时区无法确认时，该账户会显示失败或不计入相关卡片，不会猜测为零。v2.0.0 的 TT 近 7 / 28 天截至各账户时区昨天；旧版 v1.4.12 使用本机日期窗口。看板近 30 天不会再被静默映射为 TT 近 28 天，不等窗口会保持独立。

TT 未知或混合币种时不显示金额合计。不同账户或不同 ID 的同名广告系列分别统计。Google 各账户保留自己的币种，平台转化定义保持独立，缺失列显示「—」。

TT 今日页和看板读数成功后会按账户、活动与日期同步「TikTok 报表」数据集；使用官方 OAuth 连接的定时同步也通过 MCP 拉取。已配置的旧版粘贴凭据仍可由定时同步走原 Open API 路径。同步会替换成功读取的账户和日期范围，保留其他范围；同步失败时保留旧数据并提示失败；若已有更新请求完成，会提示以最新结果为准。旧格式数据集迁移时会保留独立备份，并在界面提示备份名称；若无法安全备份或写入，迁移会停止。

本地数据集最多保存 10,000 行。今日页和 TT 读数超过这个容量时仍继续巡检账户，但不覆盖数据集，会提示缩小范围；单个账户报表超过 20,000 行时，该账户显示失败并建议缩短日期范围。看板数据集卡片只在账户、日期和本次读取的数据内容完成核对后展示汇总。

v2.3.1 及更早版本中，Agent 或定时任务的近 7 天同步包含今天，与截至昨天的看板快捷范围不同。未发布候选将默认同步改为截至昨天的 7 个完整日；工具可传具体起止日期与看板总控一致，并回显实际日期。OAuth MCP 继续保留账户时区，旧版 Open API 路径沿用本机日期规则。

## 数据与安全边界

TikTok 官方授权供看板读数和对话报表工具共用；对话报表工具还会写入本地数据集，因此受会话权限和确认约束。`permission-denied` 表示本地写入未获允许，应按返回原因处理，不能据此判断 TikTok 授权失效。从「今日读数 → AI 分析」进入的会话为只读；写入看板时需要在桌面端新建允许本地写入的对话，远程只读会话仍不能写入。连接状态查询不会为检查状态而重新读取或续期 OAuth 凭据。

Renderer 只提交有界链接和已保存模块 ID，Main 校验、采集、解析并持久化，通过 typed preload 返回。看板读数使用广告平台只读请求，不修改广告、预算或状态。本地看板操作受会话权限约束：只读及远程只读会话不能写入，需确认的操作要获得批准；Agent 导入文件限定在当前授权工作区。Google 下载只点击明确的表格下载和 CSV 控件，不保存远端报表，不修改广告、预算、状态、账户或列配置。

Google 拒绝非 HTTPS、非 ads.google.com、含 URL 凭据或常见密钥参数的链接。导出前后账户、日期和来源必须一致；CSV 自有字段与页面证据冲突时拒绝。明确的当前视图总计会与可加明细核对，其他总计不混加。导入失败保留旧的有效读数。更换链接后会明确标注旧读数来自之前的链接；手动导入单独标明 CSV 来源。Google 模块始终按独立报表范围显示，整板刷新也包含它。

原始自动下载 CSV 仅供当次解析，导入完成后删除；下载失败、取消或上下文改变也清理临时文件。POSIX 平台目录权限为 0700、CSV 和汇总存储为 0600；Windows 继承当前用户 AppData 目录的访问控制，POSIX mode 位不能证明 NTFS ACL。本次未单独验证自定义 NTFS ACL。用户手动选择的原文件不删除。

本次验收中的真实账户仅用于只读验证。测试源码和报告使用虚构数据或脱敏汇总结论，不包含真实账户名称、ID、私有来源 URL、原始报表或令牌；验证不会修改广告账户。业务读数在用户本机保留实际身份以支持账户选择，不能将它直接当成可公开的脱敏材料。
