# 投手 v2.9.3

- 思考强度可以连续拖动。松手后可以再调整，点击面板外或按 Esc 收起。自动档在面板内选择，可用档位由所选模型决定。
- 首页和对话里都能点开待发送的图片，发送后也能放大查看。支持只发图片，通用文件选择器选中的图片会作为图像发送。自定义模型可以按模型配置图片输入。
- 重启后，会话的状态点、标题和更多按钮保持对齐。侧栏滚动条在指针移到条上和拖动时显示。可以把会话拖入项目整理，归属随重启保存，续聊使用原来的工作目录和授权。
- 在投手回复下点击「从这里开分支」，会保留截至该回复的上下文。新分支按原对话标题连续编号。
- 长任务显示当前步骤和已用时间。有任务计划时显示完成比例，在已有可用耗时样本时显示预计剩余时间。
- 首页的项目、插件和模型菜单向下展开。可以搜索技能、已连接服务和启用的插件。对话中可以预览已保存的看板、打开附件，也可以将本地附件另存为。
- 今日读数及连接页新增 Google Ads 预告，连接页新增七家移动衡量合作伙伴预告。

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包。

macOS 和 Windows 均通过类型检查、全量测试、OMP 兼容测试，以及安装包启动、保存和重启验证。14 项发行文件上传后通过 SHA-256 回验。[正式发布流程](https://github.com/taotao135791-bit/toushou/actions/runs/45436377881)
