## 2.0.0 版本说明

### 读数和看板

- 「今日」可按账户名选择单个 TikTok 账户，或巡检已选账户；支持逐账户刷新、查看进度、失败原因和未读取状态。自选日期最长 366 天。
- 可将当前读数保存到新看板或已有看板。默认生成可独立移动、调整尺寸和编辑的指标、图表及说明模块，并保留完整来源快照；也可选择整页报告。不同平台、币种、日期和时区的数据分开显示。
- 模块可拖动调整大小，也可在设置中输入精确尺寸。保存失败或冲突时保留设置草稿；关闭并重新打开看板后，可继续查看已保存布局。快照和图表不会自动刷新，当前汇总数据不能代表每日趋势。
- 可以用自然语言请求 AI 修改模块，预览建议后再决定是否保存。对话中可直接预览已保存的看板内容，并在核对证据后将重点加入看板；文件静态预览的内容仍需自行核实。
- 改善历史会话的恢复体验：跨工作区打开历史记录时，先切换到授权工作区并加载对应记录，无法恢复时保留提示，方便重试。

### 使用前请留意

- TikTok 通过 MCP 读取；Facebook 和 Google 使用支持的报表入口。Google 真实账户验收暂缓，Facebook 自选历史日期的真实页面仍待验证。
- 读取报表本身不调用大模型；主动发起 AI 分析或编辑会产生模型用量，首次格式修复也可能产生额外用量。AI 分析和布局最多发送所选范围内 50 个账户。
- 使用 AI 时，所选账户名称、ID、数值和你的描述可能发送给所选模型；请勿在描述中填写密钥。导出默认隐藏内置账户标识，但自定义文字和数值仍可能敏感，分享前请检查。
- 看板使用独立的 V2 本地存储，升级时保留旧版文件和迁移备份。降回旧版后可看到升级前的数据，但两版之后的修改不会自动合并。本版不提供托管分享链接。
- 桌面应用与 Windows 安装程序使用和主界面一致的三条信号柱标识。

### 验证范围

正式构建已使用授权 TikTok 账户进行只读验证，并在真实界面验证模块布局、调整尺寸、AI 修改、保存关闭、对话预览及重启恢复；未修改广告账户。自动化使用合成数据：macOS 214 个文件、2052 项测试通过及 2 项平台跳过；Windows 214 个文件、2054 项通过。两平台成品启动、保存与重启，以及上传后发行资产校验均通过。

公开 arm64 ZIP 已独立下载核对，版本、图标、架构、校验和与原始签名完整性符合预期；173 个产品代码文件与交互验收版本逐字节一致。公开包的额外窗口复测因电脑控制不可见暂未完成，不计作新的手工通过。Google 真实账户、Facebook 自选历史日期真实页面、Windows 安装器交互及自动更新仍未纳入人工验收。macOS 包使用临时签名，尚未公证。

完整功能和限制见 [HTML 看板说明](https://github.com/taotao135791-bit/toushou/blob/main/docs/v2-html-board-evaluation.md)，[正式发行构建](https://github.com/taotao135791-bit/toushou/actions/runs/41303762164)已完成。
