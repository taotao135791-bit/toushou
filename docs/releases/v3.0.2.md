# 投手 v3.0.2 · macOS

本版提供 Apple Silicon 和 Intel 安装包。[按平台下载](https://github.com/taotao135791-bit/toushou/blob/release-channels/README.md)

- **会话迁移。** 将已保存的会话拖入项目后，完整历史会移到目标项目，未发送的草稿会一并保留。正在查看的会话会在目标项目重新打开，顶部显示项目名称。默认工作区隐藏项目标签。
- **长期记忆开关。** 「设置 → 长期记忆」可以关闭投手对长期记忆的读写。已保存的条目可在设置中查看、编辑和删除。
- **在对话中修正记忆。** 投手可按关键词查找记忆，在改写或删除前展示完整内容并请你确认。取消任务、关闭长期记忆或切换到只读权限会阻止待确认的写入。

本机完成了 macOS 源码回归，并使用实际的 OMP 17.2.7 和 17.2.12 运行检查。
