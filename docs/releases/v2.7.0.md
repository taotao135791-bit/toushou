# 投手 v2.7.0

- 「连接」页在飞书下方新增钉钉，使用官方 Stream 模式连接企业自建应用的机器人。完成绑定后，可在钉钉私聊提问，用 `/ping` 检查收发，用 `/new` 开始新的对话。[钉钉接入说明](https://github.com/taotao135791-bit/toushou/blob/main/docs/dingtalk-connection.md)
- 看板显示待刷新状态，手动刷新使用已设置的账户和日期。支持按各自口径汇总百分比和人数，并把核验过的 AI 卡片提案添加到当前看板。
- 对话的流式渲染按帧合并。历史对话先显示本地预览，支持复制对话或从完整回合创建分支。删除对话、看板后可短时撤销。
- TikTok 和 AppsFlyer 会在后台尝试续签授权。文案评分支持更多语言，并核对已确认的宣传事实。

23 项钉钉专项测试覆盖界面、配对、模拟私聊收发和断线重连。Apple Silicon 成品也通过了钉钉官方网关的无效凭证拒绝检查。真实企业应用的私聊收发需要用有效凭证完成验收。

macOS 和 Windows 均通过全量测试、26 项 OMP 兼容测试和成品启动、保存、重启验证。14 项发行文件上传后通过 SHA-256 回验。[正式发布流程](https://github.com/taotao135791-bit/toushou/actions/runs/45205547355)

发行页提供 macOS Apple Silicon 和 Intel 的 DMG 与 ZIP，以及 Windows x64 安装程序。macOS 应用尚未公证，Windows 安装程序尚未签名，首次安装可能出现系统提示。
