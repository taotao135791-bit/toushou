# 投手 v2.9.9 · macOS

本次发布提供 Apple Silicon 和 Intel 安装包。Windows 正式版为 2.9.8。[按平台下载](https://github.com/taotao135791-bit/toushou/blob/release-channels/README.md)

- **任务进度。** 输入框上方显示当前步骤和预计剩余时间，进度条由左向右推进。等待确认时暂停计时。顶部栏移除了运行提示和黄点。
- **项目和会话。** 侧栏改为单行展示。运行、完成未读和失败分别用转圈、蓝点和红点表示。会话设定移到会话菜单，拖动会话到项目会迁移记录并切换顶部项目。修复了长时间打开应用后，已选会话偶尔显示为新会话首页的问题。
- **模型和外观。** 模型与思考强度合并为一个入口，新会话沿用上次选择。「设置 → 外观」可关闭发送按钮跟随鼠标的效果。
- **记忆。** 新增全局和项目记忆、历史对话检索。跨项目读取和全局写入需要确认。
