# 投手 v3.0.1 · macOS

本次提供 Apple Silicon 和 Intel 安装包。[按平台下载](https://github.com/taotao135791-bit/toushou/blob/release-channels/README.md)

- **对话执行过程。** 状态行穿插在助手的说明之间。连续的工具调用合并成一行，显示正在执行的步骤和失败提示，点击该行可查看对应记录。
- **飞书文档。** 可列出和搜索文档、读取块结构、插入和修改文字、删除块及填充原生表格。询问模式下的结构编辑和所有删除操作都需要确认。替换块文字会以纯文本覆盖原文字及其行内格式和链接。
- **飞书附件。** 上传时由用户在系统文件选择器中明确选取文件。授权需要文档编辑及附件上传权限，操作使用用户身份。

主线 macOS 和 Windows 回归通过。正式构建通过固定版 OMP 17.2.12 兼容测试、双架构打包、成品启动及 10 个发行文件回下载校验。独立的 Apple Silicon 版 3.0.0 可发现 3.0.1 更新。飞书工具验证使用本地模拟服务。Windows 渠道的正式版为 2.9.8。[正式发布流程](https://github.com/taotao135791-bit/toushou/actions/runs/46030800267) · [主线 CI](https://github.com/taotao135791-bit/toushou/actions/runs/46029480031)
