# 投手 v3.0.1 · macOS

本次提供 Apple Silicon 和 Intel 安装包。[按平台下载](https://github.com/taotao135791-bit/toushou/blob/release-channels/README.md)

- **对话执行过程。** 状态行穿插在助手的说明之间。连续的工具调用合并成一行，显示正在执行的步骤和失败提示，点击该行可查看对应记录。
- **飞书文档。** 可列出和搜索文档、读取块结构、插入和修改文字、删除块及填充原生表格。询问模式下的结构编辑和所有删除操作都需要确认。替换块文字会以纯文本覆盖原文字及其行内格式和链接。
- **飞书附件。** 上传时由用户在系统文件选择器中明确选取文件。授权需要文档编辑及附件上传权限，操作使用用户身份。
