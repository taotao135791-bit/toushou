# 投手 v2.9.2

- 在侧栏手动锁定已保存的会话，防止误删。重启或归档后仍保留锁标。删除整项目时也会检查会话锁，需要先解锁才能继续。锁定状态保存成功后才会更新界面。
- 今日读数支持选择 Facebook 广告账户。可以按名称或 ID 搜索，通过 Meta 只读 MCP 查询选定日期的单账户表现，或逐个巡检已授权账户。
- 通过「设置 → 数据 → 从其它 Agent 导入」复制 Codex 和 Claude Code 的本机对话文字，继续投手中的独立副本。Codex 压缩存档需要先解压成 JSONL。
- 输入框记住新对话和已有对话的草稿。加号菜单可选择技能、命令和 MCP，插入后可撤销。修复从设置等页面打开历史时偶尔卡在「没有活动会话」的问题，并减少长对话流式输出期间的重复计算。

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包。

macOS 和 Windows 均通过类型检查、全量测试、27 项 OMP 兼容测试，以及安装包启动、保存和重启验证。14 项发行文件上传后通过 SHA-256 回验。[正式发布流程](https://github.com/taotao135791-bit/toushou/actions/runs/45404309495)
