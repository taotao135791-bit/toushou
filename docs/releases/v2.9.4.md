# 投手 v2.9.4

- 「设置 → 对话」可按当前模型的上下文占用率自动压缩，默认 80%，可在 50% 到 95% 之间调整。当前版 Oh My Pi 会在安全的会话边界检查阈值，压缩后保留近期消息并继续原会话。
- 自动和手动压缩都会在对话流里显示进度，结束时原位显示压缩结果、跳过原因、取消或失败状态。
- 对话底部只显示累计 token 数。点击数字可查看当前上下文用量和模型窗口，也可以手动压缩。输入 `/compact` 同样可用。输入框和任务进度条下移，把更多空间留给消息。
- 从服务商目录选模型时，自动使用匹配型号的图片能力和最大上下文。新增目录外的型号时，需从 200k、256k、300k、500k 或 1M 中选择窗口，老型号沿用原配置。Gemini 可直接使用原生地址添加型号。仅支持目录的原生连接可另建兼容服务商。

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包。

macOS 和 Windows 均通过类型检查、全量测试、OMP 兼容测试，以及安装包启动、保存和重启验证。14 项发行文件已上传并通过 SHA-256 回验。[正式发布流程](https://github.com/taotao135791-bit/toushou/actions/runs/45448070178)
