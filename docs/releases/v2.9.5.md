# 投手 v2.9.5

- 阅读投手回复时，点击正文中的蓝色文件名即可打开附件。表格文件带绿色表格图标，图片带图片图标。鼠标悬停或用键盘聚焦时，文件名会显示下划线。
- 附件卡片集中显示在每条回复末尾，按文件首次出现的顺序排列。多次提及同一文件只生成一张卡片。本地文件可以从卡片打开或另存为。
- 长回复的标题、段落和列表间距经过调整。在窄窗口中，长标题和文件链接可以自然换行。
- 思考强度滑条在普通档位显示蓝色，调到当前模型的最高档时变为蓝紫渐变。轨道上的光点向左流动，开启系统「减少动态效果」后显示静态轨道。

适用平台为 macOS Apple Silicon、macOS Intel 和 Windows x64。
