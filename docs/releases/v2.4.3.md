# 投手 v2.4.3

本版修复连接配置保护、看板保存、日期提示和定时任务的稳定性问题。

## 本次修复

- MCP 配置损坏或无法安全读取时保留原文件，拒绝覆盖；连接页持续显示读取失败及重试入口。保存时检测外部修改，并通过临时文件替换。同名手写连接不再被静默替换。显式设置独立运行时目录时，通用、TikTok 与 Figma MCP 使用该目录。
- 默认计数器、仪表盘和文件卡片可以保存，清空可选字段后也能保存；非法路径和未知字段仍由原有严格校验拒绝。
- 日期摘要区分跟随总控、截止日回看、独立日期、固定值和待接通模块。固定值及本地导入数据切换日期不再提示重新查询，纯固定看板刷新不再声称已取到新数据。
- AppsFlyer 本机只读工具入口在首个会话前就绪，远端授权在后台恢复；每次读取核验当前连接，避免授权恢复稍晚导致同一会话持续缺少工具。
- 兼容按数据集名称保存的旧版 AF 查询配方，修正其日期刷新提示和连接状态；跨看板切换不会因上一块看板的手动日期状态而漏掉首次刷新。
- 定时任务成功启动不再清空运行失败计数，连续失败可以自动暂停；人工重新启用仍会重置计数。
- 飞书任务固定收件聊天，运行结果和发送状态分别记录；确认未发送时可以单独重试原内容、原目标，回执不明确时不自动重发。

## 升级说明

- **已有飞书通知任务需要编辑并选择收件聊天。** 未指定目标的旧任务仍会执行，但不会再自动发往最近私聊或群聊；界面会标记待选择收件目标。
- 修改任务的收件聊天只影响后续运行，历史结果重试仍使用该轮保存的原目标。关闭完成通知可以取消尚未开始的自动推送。
- “飞书已发送”表示服务返回消息回执，不表示收件人已读。发送中断或回执未知时，请先在飞书核对，不会自动重复发送。
- 为支持重试，尚未完成投递的摘要和目标保存在本机私有目录；成功后删除，旧条目随保留的运行记录清理。Windows 使用用户目录的既有访问控制。
- 损坏、不可读或使用符号链接的 MCP 配置会被保护性拒绝读写，原文件保留。请先修复配置或使用普通配置文件，再重试连接。
- 现有看板、数据集、账户、项目和模型设置沿用原存储，本版不执行破坏性迁移。

- arm64 本地成品实际验证默认模块保存、退出重启恢复、日期和固定板刷新提示，以及飞书任务目标与暂停状态恢复；测试使用独立目录和合成资料。
