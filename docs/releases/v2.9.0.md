# 投手 v2.9.0

- 输入框记住新对话和已有对话的草稿。重启后打开原会话即可继续编辑，失败的发送回填到原来的输入位置。
- 从输入框的加号菜单选择技能、命令或 MCP。可以用键盘搜索和选择，插入后可以撤销。切换会话会取消还在读取的技能。
- 进入「设置 → 数据 → 从其它 Agent 导入」，选择 Codex 或 Claude Code，复制本机对话文字到投手。导入结果列出新增、重复、跳过和失败的数量。可以继续投手里的副本，原应用的对话和设置保持原样。Codex 压缩存档需要先解压成 JSONL。
- 修复从设置等页面打开历史时，预览有时会切到「没有活动会话」的问题。
- 减少长对话输出期间的重复计算。草稿保存和菜单加载分开处理，减少它们对日常输入的影响。

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包。
