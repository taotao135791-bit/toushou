# 投手 v2.6.0

## 看板与对话

- 从看板菜单或聊天成果继续编辑原看板。同一业务有多张候选看板时，可以先勾选一张或多张，再一起核验和保存。
- AppsFlyer 或个别指标本次取不到时，看板和对话仍交付同一口径下已核验的读数，标记缺项，便于补取。
- TikTok 看板先绑定账户再刷新。导入报表时，账户、活动和素材 ID 按文本保留，数据行被截断时会在数据集和引用模块标明。
- 对话显示本会话权限和新会话默认权限。应用运行期间，发送失败或回执待确认时会保留队列，供同一工作区内继续处理。
- 对话输入栏根据当前会话模型显示思考档位。打开浏览器或文件面板时，保留当前页面和看板位置。
- 切换页面时复用应用监听。恢复长对话时，已完成的思考记录直接显示，实时计时跟随当前正在输出的消息。

## 在对话中指定 MCP

输入 `@`，选择已启用的 MCP，再发送要执行的请求。自动选择漏掉服务或读数失败时，可只发送所选 MCP 来继续上一项相关请求。新回合中的原生重连沿用当前会话权限。

## 升级与下载

- macOS 提供 Apple Silicon 和 Intel 的 DMG 与 ZIP，Windows 提供 x64 安装程序。发行页提供更新清单、差分文件和 SHA-256 校验文件。
- macOS 应用尚未公证，Windows 安装程序尚未签名。首次安装可能出现系统提示。

## 验证

构建和成品启动验证使用隔离资料目录。看板与对话验收使用合成数据和本机模拟模型。
