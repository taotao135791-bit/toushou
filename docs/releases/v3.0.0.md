# 投手 v3.0.0 · macOS

本次提供 Apple Silicon 和 Intel 安装包。Windows 最新正式版为 2.9.8。[按平台下载](https://github.com/taotao135791-bit/toushou/blob/release-channels/README.md)

- **附件定位。** 本地附件可以从右键菜单在 Finder 中显示。「另存为」的位置在本次运行期间按项目和会话记忆，原件移走后仍可定位有效副本。HTML 报告保持仅定位。
- **TikTok 连接。** 旧授权失效后可以直接重新连接。代理中断时沿用当前网络设置，界面显示授权失败的步骤，方便重试。
- **钉钉连接。** 钉钉显示已登录但令牌失效时，点击连接会打开浏览器，重新授权当前账号。投手会验证该账号，再恢复连接。
- **模型与思考。** 拖动思考强度只显示档位名称，键盘也可继续调整。

正式构建通过 macOS 全量测试、OMP 17.2.12 兼容测试、双架构打包、成品启动及 10 个发行文件回下载校验。Windows 的附件、连接和会话交互回归通过。在独立的 Apple Silicon 版 2.9.9 中确认可以发现 3.0.0 更新。连接回归使用合成授权数据。[正式发布流程](https://github.com/taotao135791-bit/toushou/actions/runs/45802033232) · [Windows 测试](https://github.com/taotao135791-bit/toushou/actions/runs/45801472504/job/139845717365)
