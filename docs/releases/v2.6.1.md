# 投手 v2.6.1

- 思考菜单随当前模型及接入方更新。旧版 OMP 漏报时，按同一提供方和完整模型 ID 补齐目录里已声明的档位。用户显式设置的模型能力继续生效。
- 修复 DeepSeek-V4.1-Flash 只显示「自动」和「关」。使用支持低、高、最高三档的连接时，可在输入栏分别选择。更换模型后，菜单会显示该模型的档位。
- 设置页可选用运行时识别的新模型，刷新模型目录后会同步更新可选档位。

桌面验证使用固定版 OMP 和本机模拟服务，覆盖同一对话切换模型、菜单档位变化，以及选定参数随请求发送。

发行页提供 macOS Apple Silicon 和 Intel 的 DMG 与 ZIP，以及 Windows x64 安装程序。macOS 应用尚未公证，Windows 安装程序尚未签名，首次安装可能出现系统提示。
