# 2.0.2

改进 Facebook 日常读数和文案模型池，修复看板解锁、定时执行与浏览器截图中的可用性问题。

- 「今日」页 Facebook 支持搜索、账户管理、单账户读取及全量巡检，展示进度并可停止后续账户。保存和分析只包含所选范围，未读取或失败账户不会按正常读数计算。
- 新建 Facebook 日报统一使用「FB 投放日报」，支持按产品关联已保存报表；点击「自动获取」才读取所选产品和支持日期。已有旧方案保留可用，昨天和近 3 天仍不自动导出。
- 文案模型池可一次发现并批量添加多个模型，保留大小写不同的模型和路由；修改连接地址、协议或密钥后需重新发现，迟到响应不会覆盖当前列表。模型池交付按目标语言直接生成，数量不足会明确提示。
- 模型服务故障不再被当作文案质量停滞，后续健康模型可继续接管；错误信息不再回显模型池凭证。
- 修复看板锁定后无法解锁，以及修改其它任务反复推迟定时任务的问题。检查时间随最近到期任务调整，保留启动补跑。
- 浏览器截图不再依赖网页动画回调，避免页面暂停动画时堵住后续操作。

Google 真实账户验收仍暂缓；本版不新增托管分享链接。macOS 包仍为临时签名、未公证；Windows 安装器交互和自动更新的人工验收不在本次合成验证范围内。

[正式发行流程](https://github.com/taotao135791-bit/toushou/actions/runs/41593223107)已通过：macOS 221 个测试文件、2151 项通过及 2 项平台跳过；Windows 221 个文件、2153 项全部通过。两端均通过 22 项固定版 OMP 兼容测试、正式包启动与看板保存重启、发行资产 SHA-256 校验。全部验证使用合成数据与隔离配置，未操作真实广告账户。

公开 Apple Silicon ZIP 已重新下载核对校验和、2.0.2 版本、应用身份、启动脚本及 arm64 架构，并确认关键修复已进入包内代码。两平台更新清单均为 2.0.2；公开发行包含 14 个非空文件，双 SHA 清单覆盖全部安装包、压缩包、更新清单与 blockmap。
