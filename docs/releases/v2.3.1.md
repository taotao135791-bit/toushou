# 投手 v2.3.1

- 修复 macOS 挂载设备编号变化后，项目目录仍存在却显示不可用的问题。新登记或已核验的项目使用持久卷标识及目录身份，避免把正常重挂载当成目录丢失。
- 项目不可用时显示原路径、原因和「重新选择文件夹」入口。同路径确认保留项目与会话；选错目录会提示重新选择，不会创建另一个项目。默认保存位置也可以恢复。
- 修复目录恢复后红色错误仍不消失、折叠项目列表后错误没有反馈，以及已归档项目只提供无效刷新操作的问题。
- 项目列表、实时会话和历史会话入口使用同一项目检查，避免通过旧最近目录入口绕过不可用或归档状态。

旧版项目记录如果缺少持久卷标识且设备编号已经变化，需要重新选择原文件夹确认一次。无法取得持久卷标识的文件系统继续使用严格验证；删除项目会重新核验本次挂载与目录身份。详见[项目说明](https://github.com/taotao135791-bit/toushou/blob/main/docs/projects-and-session-topics.md)。

macOS 提供 Apple Silicon / Intel 安装包，Windows 提供 x64 安装程序。首次安装说明见 [README](https://github.com/taotao135791-bit/toushou#下载与安装)。
