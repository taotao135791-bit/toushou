# 投手 v2.9.6

- 可以在投手对话中创建钉钉在线文字文档，也能向已有文档追加 Markdown 正文。默认保存到「我的文档」，也可以指定有写入权限的文件夹。成功后会返回钉钉文档链接。
- 本地附件卡片增加了在 Finder 或 Windows 文件资源管理器中定位文件的入口。回复中给出了交付目录时，正文和卡片里的文件名会关联到该目录。文件组只给出范围简写时，可以打开目录查看。
- 历史会话预览在列表刷新后也可以继续打开附件和所在文件夹。

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包。

macOS 和 Windows 均通过类型检查、全量测试、OMP 兼容测试，以及安装包启动、保存和重启验证。共发布 14 项文件，安装包、更新清单和差分更新文件已回下载并通过 SHA-256 校验。[正式发布流程](https://github.com/taotao135791-bit/toushou/actions/runs/45580955313)
