# 投手 v2.2.0

- 连接页新增 AppsFlyer 官方连接和官方 Logo。在官方页面登录授权即可读取应用与聚合事件，无需手填 API Token，支持取消、断开、重试和重启恢复。
- 看板分析和对话可使用同一条连接。随应用提供的专用查询工具支持只读会话，仅开放应用列表和事件读数，不开放创建链接等远端写入能力。
- 支持查询事件次数和独立用户数，区分活动日期与 LTV 口径。与 TikTok 关联时保留活动 ID、日期、时区和币种；活动关联不等于两边事件定义和归因窗口相同。
- 修复 Windows 生产包冒烟测试的清理误报，终止工具返回非零后继续核验进程身份；无法确认退出仍阻止发布。

候选生产包已通过官方授权、真实聚合读数、只读工具调用、重启恢复和断开清理验证。精确事件映射和不同时区的数字对账尚未完成，请先核对口径。

测试授权已清理。源码、测试夹具及发行说明使用合成数据或脱敏结论，不包含真实账户标识、读数或凭据。使用说明见 [AppsFlyer 接入说明](https://github.com/taotao135791-bit/toushou/blob/main/docs/appsflyer-connection.md)。

## 安装

macOS 提供 Apple Silicon / Intel 的 DMG 与 ZIP，Windows 提供 x64 安装程序。安装包及自动更新清单由 GitHub Actions 构建，并提供 SHA-256 校验文件。

## 发布核验

应用源码固定在原始 v2.2.0 标签，未移动标签。macOS 产物来自[原始发布流程](https://github.com/taotao135791-bit/toushou/actions/runs/41667557518)；Windows 使用同一标签重建，并在[恢复流程](https://github.com/taotao135791-bit/toushou/actions/runs/41671021853)通过更新后的进程采集、保存重启和退出清理检查。恢复流程仅更新 CI 检查工具。

两平台检查、完整校验清单及 14 项上传资产的摘要已核对，自动更新清单均为 2.2.0。源码、候选包及公开发行材料未发现真实账户数据或凭据。
