# 投手 v2.7.2

- 「连接 → 钉钉」改为一键账号登录。投手会自动准备官方钉钉 CLI，已有登录可直接复用，需要授权时会打开系统浏览器。授权通过后，卡片显示已连接的钉钉账号和组织。[钉钉接入说明](https://github.com/taotao135791-bit/toushou/blob/main/docs/dingtalk-connection.md)
- 连接后可以在投手对话中搜索钉钉消息、搜索文档和阅读文档。组织需开通 CLI 访问。使用 v2.7.0 机器人连接的用户升级后，可点击「钉钉账号登录」重新连接。

发行页提供 macOS Apple Silicon 和 Intel 的 DMG 与 ZIP，以及 Windows x64 安装程序。macOS 应用尚未公证，Windows 安装程序尚未签名，首次安装可能出现系统提示。
