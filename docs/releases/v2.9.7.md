# 投手 v2.9.7

- 可以直接操作钉钉在线表格和多维表。例如，指定表格链接和工作表后，可以读取一段区域，或把核对好的数据写进指定单元格。
- 钉钉连接支持 28 个业务类别中的 768 项操作，包括文档、钉盘、知识库、日程、待办和审批。投手会按需查询当前任务所用的操作与参数，沿用已绑定账号的组织权限。
- 群聊、私聊、机器人、DING 和邮件的直接发送入口均已关闭。创建待办或办理审批时，钉钉可能按组织设置产生系统通知。
- 上传或下载文件时，由你在系统窗口选择来源或保存位置。删除、权限调整等操作会显示一次确认。

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包。

已用官方 CLI 在隔离环境预演普通表格的读取、区域更新和追加行，以及多维表记录的新增和更新。预演核对了参数与目标区域，服务端实际写入仍取决于账号权限。[钉钉连接用法](https://github.com/taotao135791-bit/toushou/blob/v2.9.7/docs/dingtalk-connection.md)

macOS 和 Windows 均通过类型检查、全量测试、OMP 兼容测试，以及安装包启动、保存和重启验证。共发布 14 项文件，安装包、更新清单和差分更新文件已回下载并通过 SHA-256 校验。[正式发布流程](https://github.com/taotao135791-bit/toushou/actions/runs/45585919737)
