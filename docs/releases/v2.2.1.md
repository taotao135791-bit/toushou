# 投手 v2.2.1

- 对话按用户回合整理执行过程与结果，常用工具显示易懂的动作、来源和实际状态，原始详情仍可展开。看板预览聚合显示，支持切换画面及展开查看。
- 加入 Facebook、TikTok、飞书、Google Ads、Figma、AppsFlyer 官方标识，明确网页来源显示 favicon；修复 macOS 无法读取部分 ICO 的兼容问题，GitHub 使用其官方图标。
- 加深发送气泡，复制和加入看板统一显示，语言选择移入设置；修复深色按钮文字对比不足的问题。
- 看板默认底色更柔和，移除模块缩放控件的圆框，保留缩放和尺寸设置。今日读数统一由右侧内容区滚动，侧栏、顶部标签及其它工作面板保持独立；切换看板不再沿用今日页的滚动位置。
- 修复长对话中加入看板、加入任务和回滚确认弹窗被裁切的问题，保存与关闭完整可见；补齐连点和迟到响应保护。
- 优化历史对话重绘、工具结果解析和图标加载；保留会话阅读位置，向上阅读时避免被新内容拉回底部。

本轮界面验证使用独立合成数据，没有操作真实广告账户，也没有将真实账户资料或凭据写入仓库。本版不新增广告读数权限；Google 真实账户验收及更多网站在特殊代理网络下的 favicon 显示仍有既有覆盖限制。

macOS 提供 Apple Silicon / Intel 的 DMG 与 ZIP，Windows 提供 x64 安装程序。安装包和自动更新清单由 GitHub Actions 构建；发布流程核验双平台测试、OMP 兼容、生产包启动与保存重启，以及上传前后的 SHA-256 校验。macOS 尚未公证，首次安装说明见 [README](https://github.com/taotao135791-bit/toushou#下载与安装)。
