# 投手 v2.4.1

v2.4.1 修复 2.4.0 看板日期切换和 AppsFlyer 当天数据的两处体验问题；看板生成、刷新绑定和新模块能力沿用 v2.4.0。

## 本次修复

- 切换总控日期只更新日期口径，不再自动发起媒体/AF 查询。点击「刷新全部模块」或模块刷新后才真正取数，并显示“日期已切换，点击刷新获取新日期数据”的待刷新提示，避免误触发 MCP 查询。
- AF 当天窗口允许 AppsFlyer 返回的截至当前部分数据，并在看板标注“AF 当天为截至现在的部分数据”。历史日期仍只接受完整数据，`truncated` 和行数上限结果仍视为不完整。
- AF 当天没有返回数据时显示“今天暂无数据（截至现在）”，不再显示笼统的“AF 更新失败”。

## 升级说明

- 从 v2.4.0 升级：现有看板、数据集、查询配方、账户、项目和模型设置保留。
- 日期切换改为手动刷新后，切换日期时旧数据不会冒充新日期数据；请确认日期口径后点击刷新。
- AF 当天数据是截至刷新时刻的部分结果，后续同一天的完整数据可能不同；需要完整日数据时请刷新昨天或更早的完整日期。
- 回退到 v2.3.1 前请备份看板文件；旧版会丢弃 2.4.0 新增的表格、漏斗和分析模块，AF 数据集状态也可能丢失。

## 已知限制

- AF 当天 partial 数据只代表本次刷新时刻，不能当作完整日终数据。
- 看板生成验证使用合成来源的小样本，不代表所有客户、模型和用途；AI 输出的文字结论需要人工复核。
- 数据表格当前绑定单个数据集，不提供跨来源实时拼表。
- Meta、Google、AppsFlyer 的实际账户核对范围见 [README](https://github.com/taotao135791-bit/toushou#使用限制) 和接入说明。
- macOS 应用尚未公证，首次打开若被拦截，可右键点击应用并选择「打开」；Windows 未签名，首次安装可能出现 SmartScreen 提示。

完整功能清单见 [v2.4.0 发布说明](https://github.com/taotao135791-bit/toushou/blob/main/docs/releases/v2.4.0.md)。
