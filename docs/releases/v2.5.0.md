# 投手 v2.5.0 · 轻盈版

首页和侧栏采用轻盈版设计。切换到看板时，侧栏沿用相同外观，并保留已保存的宽度。

## 本次更新

- Agent 首页精简了输入区、工作区和快捷入口。对话输入栏会明确显示当前工作区和排队状态。
- 看板入口和页头使用同一款三圆加号图标。看板保留原有工作区布局、配色和读数流程，刷新和日期状态更易区分。已保存的看板可用键盘打开。
- 连接页统一显示授权状态。令牌过期时给出明确提示，飞书机器人连通但权限不足时会标明。
- 自动任务弹窗支持键盘打开、关闭并恢复焦点，固定调度显示本机时区，运行和飞书送达结果分别显示。
- Windows 首次启动提供 PowerShell 安装命令。插件、技能库、模型设置、浏览器和表格精简了说明或控件名称。

## 升级与下载

- 可从 2.4.3 直接升级。现有项目、会话、看板、数据集、模型和授权沿用原存储。
- macOS 提供 Apple Silicon 和 Intel 的 DMG 与 ZIP。Windows 提供 x64 安装程序。发行页同时提供更新清单、差分更新文件和 SHA-256 校验文件。
- macOS 应用尚未公证，Windows 安装程序尚未签名。首次安装可能出现系统提示。
