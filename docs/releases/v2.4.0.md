# 投手 v2.4.0

v2.4.0 将 2.4.0 Beta 的看板生成、刷新与业务数据分析能力并入正式版。广告平台读数仍使用只读请求；本机看板与文件操作遵循会话权限和确认设置。

## 本次更新

- 看板生成先冻结当前用户请求，在隔离草稿中保存看板、数据与查询配方；旧组件工具也须绑定本次草稿。正式保存由 Main 按冻结要求、真实查询证据与最新版本验收后整体提交，缺粒度或指标不自动降级成另一份正式看板。
- 看板刷新和日期切换实际重新查询媒体与当前绑定的 AppsFlyer 数据；刷新限定于本看板，不再遍历全局 AF 查询。空结果、失败及尚未绑定查询分别反馈，旧读数不会冒充新日期结果。
- 总控显示所选范围的具体起止日期；带相对日期的读数标题、实时模块和看板名称末尾的报表日期与实际窗口对应，固定模块不再显示为随总控更新。TT 与 AF 同步工具均可传精确日期，默认近 7 个完整日截至昨天。
- 新增数据表格、多来源阶段漏斗和随绑定数据重算的简短分析模块；日报可直接查看明细表。支持总控日期、截至报表日回看及固定历史日期，昨日日报与七日趋势分别真实取数。
- 广告数据看板默认保留可刷新的查询绑定。AF 事件先按业务语义发现匹配，支持不以 `af_` 开头的自定义事件；全部地区不再作为字面值 `all` 过滤。
- 无具体方向的业务看板采用可刷新指标、日期趋势、业务漏斗、简短分析及三方对应的兜底方案；明确的用途、风格、结构和后续修改优先，不强制套回同一模板。应用、媒体来源和事件映射使用当前任务发现并确认的范围，不内置客户专属事件、账户或业务阶段。
- 对话支持看板和模块的受控样式、精确网格布局及总控日期定制；可先预览，再按读取版本整体保存。版本冲突或非法变更拒绝写入，纯外观修改保留原数据绑定与未指定属性。
- 新增只读生成检查，按默认方案或本次明确要求检查已保存配置与数据状态；广告/素材等显式粒度以实际可见维度与有效 ID 为证，不能用活动数据或标题替代。未通过会返回缺失项和问题，不将工具调用完成当作验收通过。原生模块保存后提供经核验的看板入口。
- AF 新查询使用完整应用与名称生成稳定标识；重复查询保留已有数据集身份。达到 20 组查询上限时明确失败并保留旧配方，已有查询仍可更新，不再静默淘汰旧绑定。
- 在正式版与独立 Beta 安装之间切换时，托管工具包跟随当前应用资源位置，首个会话等待同步完成；主动停用、移除及自行安装的同名插件保留原选择。

## 升级、Beta 与回退

- 从 v2.3.1 升级：现有看板、数据集、查询配方、账户、项目和模型设置保留；2.4.0 新增的表格、漏斗和分析模块会写入现有看板存储。
- 2.4.0 正式版与 2.4.0 Beta 是独立安装。Beta 看板保存在自己的兼容副本中，不会自动并入正式版；需要保留 Beta 成果时，请在 Beta 中导出或截图，或继续使用 Beta。
- 打开 Beta 前先退出正式版，两版共用单实例锁；打开正式版前也请先退出 Beta。
- 回退到 v2.3.1 前请备份看板文件；旧版不认识 2.4.0 新增的表格、漏斗和分析模块，读取时会丢弃，AF 数据集状态也可能丢失。

## 已知限制

- 看板生成验证使用合成来源的小样本，不代表所有客户、模型和用途；AI 输出的文字结论需要人工复核，主动发起 AI 分析或编辑可能产生模型费用。
- 数据表格当前绑定单个数据集，不提供跨来源实时拼表；看板刷新和日期切换会实际重新查询绑定来源。
- 明确要求广告或素材粒度时，只有真实可见的广告/素材 ID 与数值能通过验收，活动级数据不会被当作素材级数据。
- Meta 授权和数据访问经过第三方 Pipeboard，看板日期范围使用本机日历，可能与广告账户时区不同；读数尚未与广告后台逐项核对。Google 真实账户验收暂缓，链接读取支持的页面和报表口径有限。详见[多平台读数](../multi-platform-readings.md)、[Meta 接入说明](../meta-ads-connection.md)和[AppsFlyer 接入说明](../appsflyer-connection.md)。
- 自选日期最长 366 天；AI 分析及布局生成最多发送所选范围内 50 个账户；快照和图表不会自动刷新，汇总数据不包含每日趋势；不提供托管分享链接。
- macOS 应用尚未公证，首次打开若被拦截，可右键点击应用并选择「打开」；Windows 未签名，首次安装可能出现 SmartScreen 提示。
