# 投手 v2.8.0

- 新增 TikTok + AppsFlyer 建板模板，支持批量拉取 AF 数据。建板可复用当前授权下相同口径的近期完整数据。某些查询失败时，对话和看板继续交付已核实的数据，并标明缺项。
- 打开看板时按已验证的广告主与模块日期显示缓存数据。模板按本轮应用、配方和日期核对绑定，后续可继续手动刷新。缺少有效范围记录的 TikTok 数据会提示刷新。
- 建板期间，支持中档思考的模型可临时降低高档思考力度。建板结束、中止或继续对话时恢复，用户手动设置优先。
- TikTok 报表 API 使用已解析的代理线路，AppsFlyer 授权和数据请求走直连。Windows 删除会话时重试暂时锁定的原文件。

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包。
