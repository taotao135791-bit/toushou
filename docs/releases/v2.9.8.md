# 投手 v2.9.8

这是 macOS 和 Windows 的双端过渡版，改动集中在安装包发布和应用内更新。使用 2.9.7 的用户可以在投手里检查更新，按原有方式安装 2.9.8。

从 2.9.8 起，投手检查当前系统可用的正式版。以后某个平台先发修复时，另一端继续显示自己的最新版本。macOS 提供 Apple Silicon 和 Intel 两种安装包，Windows 提供 x64 安装程序。

开发者继续向同一个 `main` 分支提交，在发布时选择平台。[并行开发与提交指南](https://github.com/taotao135791-bit/toushou/blob/v2.9.8/docs/commit-and-release.md)
