# 投手 v2.9.8

这是 macOS 和 Windows 的双端过渡版，改动集中在安装包发布和应用内更新。使用 2.9.7 的用户可以在投手里检查更新，按原有方式安装 2.9.8。

从 2.9.8 起，投手检查当前系统可用的正式版。以后某个平台先发修复时，另一端继续显示自己的最新版本。macOS 提供 Apple Silicon 和 Intel 两种安装包，Windows 提供 x64 安装程序。

开发者继续向同一个 `main` 分支提交，在发布时选择 macOS、Windows 或双端。[并行开发与提交指南](https://github.com/taotao135791-bit/toushou/blob/main/docs/commit-and-release.md)

macOS 和 Windows 均通过测试、打包和成品启动、保存及重启验证。14 个发行文件已从公开地址下载并校验，两个平台的公开更新清单均指向 2.9.8。[正式发布流程](https://github.com/taotao135791-bit/toushou/actions/runs/45604937598)

在独立的 Apple Silicon 应用副本上，2.9.7 已实际下载并安装 2.9.8。重启后，新版通过 Mac 通道检查并显示已是最新。Windows 的旧版更新器和新版通道都已验证能找到正确的 x64 安装程序，覆盖安装尚未实测。

本次恢复发布保留原始标签。两端安装包都从 [39d7f3e](https://github.com/taotao135791-bit/toushou/commit/39d7f3e74bf693c3e80756364264b428cfb9bda7) 生成。Mac 和 Windows 单端预检也分别通过。[Mac 单端验证](https://github.com/taotao135791-bit/toushou/actions/runs/45600207874) · [Windows 单端验证](https://github.com/taotao135791-bit/toushou/actions/runs/45601020192)
