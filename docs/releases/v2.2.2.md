# 投手 v2.2.2

- AppsFlyer 授权使用受控的应用内窗口；修复授权回调未送达和常驻看板使用过期令牌的问题。取消或断开会关闭本次授权窗口。
- 循环任务支持沿用对话及重置。关闭复用、切换项目后开启新上下文，旧轮次的迟到状态不会重新绑定旧会话。
- Windows 更新下载加入停滞检测、断点续传及 SHA-512 校验，修复清单等待、重试状态和静默安装后的启动行为。
- AF 查询条件可记录为命名数据集，由看板刷新拉取；读数模块与数据卡显示来源，便于区分广告后台和 MMP 数据。

AF 数据集仍按名称全局管理，刷新可能影响其它看板的共享数据集。部分结果与空结果的处理保留既有逻辑，本版不保证完整报表汇总或不同看板的日期隔离；应结合来源与日期复核，详见 [AppsFlyer 说明](https://github.com/taotao135791-bit/toushou/blob/main/docs/appsflyer-connection.md)。

验证使用合成数据和隔离资料目录，不操作真实广告账户。新的 AF 应用内授权流程尚未重新进行真实账户验收；本版不改变此前 Google 真实账户验证暂缓的范围。

macOS 提供 Apple Silicon / Intel 安装包，Windows 提供 x64 安装程序。安装包与自动更新清单通过 GitHub Release 提供，首次安装方法见 [README](https://github.com/taotao135791-bit/toushou#下载与安装)。

## 发布核验

安装包源码固定在 [`e5a3e9a63ea844a33b2c7a3778dd706e5039ec64`](https://github.com/taotao135791-bit/toushou/commit/e5a3e9a63ea844a33b2c7a3778dd706e5039ec64)，对应不可移动的 `v2.2.2` 标签。[PR 检查](https://github.com/taotao135791-bit/toushou/actions/runs/41960012811)及[双平台正式发布流程](https://github.com/taotao135791-bit/toushou/actions/runs/41960680183)均通过，包括全量测试、固定 OMP 兼容、正式包启动与保存重启、上传后全部发行文件的 SHA-256 回验。

公开版本为 stable/latest，共 14 项发行文件。两份 SHA-256 清单与 GitHub 上传摘要一致；下载后的四份清单和更新元数据也核对摘要，并检查版本、文件名、大小及更新清单字段一致性。README 和更新日志在正式公开后同步更新，真实账户资料及凭据未用于本次验证。
