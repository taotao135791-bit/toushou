# 2.1.0

新增项目管理与会话主题，改善多项目切换和前端性能。

- 会话从首条消息显示简短主题，同一对话模型可随工作内容更新；手动改名优先，重启与历史恢复后继续保留。
- 可从侧栏或输入框创建项目、添加已有目录、查看路径、归档和恢复。删除需再次确认，将项目目录与可核验归属的会话文件移入系统废纸篓；无法确认归属的旧或损坏记录保留。
- 未选择项目时显示「不在项目中」，文件仍保存在默认工作区。默认工作区不占项目列表；项目下能找到所属对话，底部会话汇总也能找到。
- 修复跨项目首次点击未打开、快速往返切换后一直加载、旧请求抢回当前会话及菜单闪动。会话操作收进更多菜单，窄窗口保留标题与可滚动的会话汇总。
- 启动时自动检查更新，仅发现新版本时提示；保留手动检查，下载和安装由用户主动操作。
- 前端生产脚本压缩，历史会话合并和查找减少重复遍历，后台会话更新不再引发当前聊天的无关渲染。合成基准和验证范围见[前端性能说明](https://github.com/taotao135791-bit/toushou/blob/v2.1.0/docs/frontend-performance.md)。
- macOS 原生红绿灯略向窗口内侧移动，保留系统尺寸、交互和窗口外轮廓。
- 修复 Windows 部分系统目录不可用时的启动失败；无法确认系统目录保护范围时暂不允许删除项目。

会话主题使用当前对话模型，不另外启动命名模型任务；相关交互仍计入当前对话用量。项目删除后的文件可从系统废纸篓还原，再添加已有目录。详细规则见[会话与项目说明](https://github.com/taotao135791-bit/toushou/blob/v2.1.0/docs/projects-and-session-topics.md)。

本轮验证使用隔离配置与合成数据，未操作真实广告账户。Google 真实账户验收仍暂缓；当前不提供托管分享链接。macOS 包仍未公证；Windows 安装器交互和自动更新的人工验收不在合成测试范围内。
