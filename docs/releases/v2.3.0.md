# 投手 v2.3.0

- 连接页新增 Meta Ads，只读接入由 Pipeboard 提供的第三方 MCP，支持浏览器授权、重新授权和断开。投手只开放账户列表和表现查询。
- 新增 Meta 原生看板，可选择已授权账户，按总控日期读取消耗、展示和点击，并刷新指标卡及每日趋势。旧空模板可由用户主动升级；已有报表和手动导入保留。
- Meta / Facebook 对话请求默认使用该连接。旧 Ads Manager 网页抓数暂停；已有历史和报表保留。

看板总控使用电脑本地日历日期，账户统计时区不同时，“今天”和“昨天”可能与 Meta 后台不同。授权、账户列表和小范围读数已验证，但尚未与广告后台逐项核对；服务和账户权限、额度及分页限制仍适用。授权及数据访问经过第三方 Pipeboard，具体权限以授权页面为准。详见 [Meta Ads 连接说明](https://github.com/taotao135791-bit/toushou/blob/main/docs/meta-ads-connection.md)。

macOS 提供 Apple Silicon / Intel 安装包，Windows 提供 x64 安装程序。首次安装说明见 [README](https://github.com/taotao135791-bit/toushou#下载与安装)。
