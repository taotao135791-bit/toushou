# 钉钉连接

## 登录与验证

1. 在投手打开「连接 → 钉钉」，点击「钉钉账号登录」。投手会复用兼容的官方钉钉 CLI，首次缺少客户端时会自动下载并校验官方发行文件。[钉钉 CLI 官方发行](https://github.com/DingTalk-Real-AI/dingtalk-workspace-cli/releases/tag/v1.0.69)
2. 如果浏览器打开钉钉授权页，选择组织并授权。组织还没开通 CLI 访问时，按授权页提示向管理员申请。通过后回到投手重新点击登录。[钉钉官方授权说明](https://github.com/DingTalk-Real-AI/dingtalk-workspace-cli/blob/main/README_zh.md#开始使用)
3. 投手自动验证连接并显示账号和组织。可以点击「检查连接」复验，也可以在投手对话中输入「在钉钉里搜客户群消息里的周报」或「找标题有投放复盘的钉钉文档，打开我指定的那份」。查询范围由授权账号的权限决定。[钉钉官方命令文档](https://open.dingtalk.com/dingtalk-dev/wiki)

## 日常使用

- 如果本机已经登录钉钉 CLI，投手会直接验证并连接该账号。连接成功后，投手固定使用这次确认的账号和组织。退出或切换终端的默认账号后，投手仍按已绑定的身份验证。
- 可以搜索和读取当前账号有权查看的聊天消息。要撤回自己已发送的消息，请指定会话和消息。群管理员也可以在权限范围内修改群名、管理成员或设置群禁言。
- 账号授权由钉钉 CLI 保存，投手只记录绑定的账号和组织标识。断开投手连接后，CLI 的现有授权仍可供其他程序使用。
- 使用 v2.7.0 机器人方式的用户升级后，需要点击「钉钉账号登录」完成一次新的授权。[v2.7.0 连接历史](https://github.com/taotao135791-bit/toushou/blob/v2.7.0/docs/dingtalk-connection.md)

## 查看工作区支持的操作

在普通桌面对话中问「钉钉工作区支持哪些操作？」可以查看已接入的服务。想了解其中一项时，可以继续问「电子表格可以做哪些操作？读取一个区域需要提供什么？」投手会按需查看对应操作及其参数。实际可访问的内容和可做的修改由当前账号、组织和目标资源的权限决定。

| 你想做的事 | 可以这样说 |
| --- | --- |
| 读取电子表格 | 「读取这份钉钉表格的『周报』工作表 A1:D10，按地区汇总。」附上表格链接，并指明工作表。 |
| 更新电子表格 | 「把这份表格的『周报』工作表 B2 填为 120，B6 填公式 =SUM(B2:B5)，再读回核对。」提供目标范围，说明哪些格子要清空或保留。 |
| 添加多维表记录 | 「在这份钉钉多维表的『测试记录』数据表新增一行，名称填『样例』。」附上目标表链接，并说明要填哪些字段。 |
| 查日程和待办 | 「列出我明天的日程，再看看有哪些待办还没完成。」 |
| 查看其他能力 | 「列出钉钉工作区支持的其他服务，告诉我其中哪项能办这件事。」 |

对支持的云盘上传、下载及表格导入导出操作，投手会打开系统文件窗口。上传或导入时选择源文件，下载或导出时选择保存位置。取消窗口即可结束这次文件操作。

工作区连接不代发聊天消息、群公告、邮件或 DING。审批流等业务操作完成后，钉钉可能按组织规则产生系统通知。

若目标有同名文档或工作表，先选定具体的一份。查询可能会分页，要求投手继续读取即可；如只能读取部分记录，汇总时应注明覆盖范围。

## 创建、追加和覆盖在线文档

- **新建文档。** 在投手对话里说「在钉钉新建在线文档《周报》，把上面的摘要作为正文」。默认保存在「我的文档」。如果要存到其他文件夹，请提供钉钉文件夹链接或节点 ID。新建时可以只给标题，也可以同时提供 Markdown 正文。
- **追加正文。** 提供已有钉钉在线文字文档的链接或文档 ID，说「把这段待办追加到文末」。新增内容接在原有正文之后。只有标题时，可以先让投手搜索，再从同名结果中选定目标。
- **覆盖全文。** 指定在线文字文档，提供替换后的完整正文，再说「用这份内容覆盖文档全文」。投手会显示目标和本次改动的预览。核对后点「允许一次」，写完可再读回原文档。

## 写入权限与结果核对

请在投手桌面的普通对话中用「询问」或「完全访问」修改钉钉内容。「询问」模式下，OMP 可能先请求工具权限，随后投手会显示钉钉写入确认框，供你核对目标和要提交的改动。「完全访问」可以直接执行普通写入。撤回本人消息、增删群成员、修改群名、覆盖文档全文、删除或调整权限等操作，每次都需要在系统确认框中点击「允许一次」。本次授权只适用于当前操作。创建文档需要目标文件夹的创建权限，追加或替换正文需要目标文档的编辑权限。

若连接中断或写入结果尚未确认，请先让投手读取目标核对。例如，更新表格后读回对应单元格，创建文档后按标题查找，追加正文后查看文末。核对前请勿重复提交同一修改。

「只读」会话可用于查询，投手会阻止写入。「禁止运行命令」可用的工具取决于 OMP 版本。如果受限会话启动失败或找不到钉钉工具，请新建「询问」模式的桌面对话。
