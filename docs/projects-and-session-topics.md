# 会话主题、项目与启动更新

会话从首条消息显示简短主题。同一对话模型可以在首轮及工作主题变化时更新侧栏主题，元数据工具只允许修改当前会话的自动标题；手动改名优先，晚到结果不会覆盖新主题。自动标题会移除密钥形态、账户编号等不适合出现在侧栏的内容。旧版已有名称保留，历史恢复及重启使用持久化名称。

这不会另外启动独立的命名模型任务；主题工具的少量交互仍计入当前对话用量。模型没有调用主题工具或工具暂不可用时，首条消息生成的本地短主题仍可使用。

侧栏「项目」的加号和输入框「选择项目」使用同一份项目列表。新建时输入名称，再通过系统对话框选择父目录；也可以添加已有文件夹。项目路径可查看和复制，归档保留目录和会话，在「已归档项目」中恢复。

目录暂不可用时仍显示原路径，并区分未找到、无法访问和需要重新确认目录。点击该项目的「重新选择文件夹」，在系统选择器中选回原目录，即可保留项目身份和原有会话；选错目录会提示重选，不会新建项目或搬移会话。要使用另一个目录，选择「添加已有文件夹」。目录恢复后刷新会清除已解决的错误；已归档项目须先恢复，再打开会话。

macOS 项目登记保存持久卷 UUID、目录编号和可用的创建时间，以适应重新挂载后设备号变化。旧记录在原有身份仍匹配时自动补齐；旧记录设备号已变化且缺少持久标识时，需要通过系统选择器确认一次。无法获得持久卷标识的文件系统仍采用严格校验。删除始终重新核对当前挂载与目录身份，确认过程中目录被替换或重新挂载会中止。

输入框只显示「不在项目中」，内部默认工作区不出现在项目列表中。未选项目的对话和文件保存在文稿目录下的「投手工作区」，不会要求用户先建项目。归档当前项目后会退回默认保存位置。项目可展开显示所属对话，这些对话也会保留在底部会话汇总中。

项目对话和底部汇总分别滚动，展开状态及滚动位置在刷新时保持。正在打开的会话提供「更多」菜单，可置顶、改名、归档和删除，不挤占标题空间；完整名称也可悬停查看。快速切换、快捷键新建及输入框选项目以最后一次操作为准，不由迟到的历史读取结果切回先前会话。首条消息或读数分析创建较慢时，已提交工作仍归原会话，后台完成不会覆盖新对话的输入。

删除项目会再次显示原生确认，列出完整目录及可核验归属的会话数量，再将这些文件移入系统废纸篓。运行中或等待操作的会话、任务须先停止；空闲会话的进程须退出后才处理目录。默认工作区、系统及用户重要根目录、包含其它项目的位置受到保护。无法安全确认归属的旧或损坏会话记录会保留，不能保证清除这些记录；目标布局不可读时操作会停止并保留项目目录。删除后的恢复需先从系统废纸篓还原文件，再添加已有目录。

系统的桌面、文稿或下载目录暂不可用时，应用仍可启动；文稿目录无法读取时会使用用户主目录下的 Documents 作为默认保存位置。无法确认系统目录的完整保护范围时暂停项目删除，请恢复目录访问后重启应用再试。

应用启动约 10 秒后检查新版本，长时间运行时约每 6 小时复查。自动检查没有新版本或网络失败时不显示提示；发现新版本才显示可操作提示。同一版本关闭后本次运行不反复弹出，新版本或下次启动可再次提示。手动检查在设置中继续提供检查中、已是最新版及失败结果；不会自动下载或安装。

开发验收如需隔离运行时资料，须使用绝对路径的 `PI_CODING_AGENT_DIR`，并避免与命名 OMP profile 组合；相对路径、无效值及命名 profile 组合沿用原有目录回退，不能作为隔离保证。应用 userData 也需单独指定。验收示例和日志只使用合成数据，不提交用户资料或凭证。
