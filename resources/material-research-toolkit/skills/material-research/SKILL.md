# 素材研究成文（MCP 找素材 → 飞书成文）

把"查素材"和"写文档"串成一条流水线：素材数据来自 MCP 服务（连接后自动获得 socialpeta_* 等工具），产出落到用户的飞书文档。

## 前置检查（每次任务开始时，按顺序）

1. **MCP 素材服务可用吗？** 会话里是否能看到名称含 socialpeta（或用户提到的素材服务名）的工具。
   - 看不到 → 判定为未连接：回复里说明"需要先连接素材服务"，并**在回复末尾单独一行输出标记** `[[connect:mcp]]`（渲染层会弹出带"去连接"按钮的引导卡），然后停止，等用户连接后重试。
2. **飞书可用吗？** 会话里是否能看到 feishu_doc_create / feishu_doc_append 工具且用户已连接飞书。
   - 未连接 → 同上，输出标记 `[[connect:feishu]]` 并停止。
3. 两者就绪 → 继续流程。

## 工作流

### 第一步：明确研究 brief

从用户请求中提炼（缺了就问，一次问全）：
- 产品/品类或竞品名
- 目标市场/国家、平台（如 Meta / TikTok / AppLovin）
- 素材类型偏好（视频/图片）、数量目标
- 关注维度（钩子、卖点、时长、投放量级、落地页）
- 交付文档标题偏好

### 第二步：MCP 检索素材

- 使用素材服务提供的工具按 brief 检索（关键词 + 市场 + 平台筛选）
- 检索结果不足时：换关键词近义、放宽市场或时间窗，最多两轮；仍不足则如实说明并交付已有部分
- 记录每条素材的关键事实（来源、数据指标），**不编造**检索结果里没有的字段

### 第三步：分析与整理

- 按维度归纳：高频钩子类型、卖点表达、素材形式规律、可复用做法
- 挑选 Top 素材（说明入选理由，用检索到的数据支撑）
- 标注每条结论的依据来自哪条素材数据

### 第四步：写入飞书文档

1. `feishu_doc_create` 建文档（标题 = 「{主题}素材研究 · {日期}」）
2. `feishu_doc_append` 分段写入：研究概要 → 数据总览 → Top 素材清单 → 规律与建议 → 附录（检索条件）
3. 每段追加后确认成功；失败时重试一次，仍失败向用户报告已写入的部分与剩余内容

### 第五步：交付

回复用户：文档链接（或文档标题）+ 三条最关键发现的摘要 + 建议的下一步（如"按某钩子方向出一版文案"可衔接 ads-copy 技能）。

## 纪律

- 素材数据只来自 MCP 检索结果，引用要能对得上；推测要标"推测"
- 飞书写入是"写"级操作，按用户批准流程执行
- 一次任务一个文档；追加优于重建
